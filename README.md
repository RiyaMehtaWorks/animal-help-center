# AnimalHelpCenter

An app where a caregiver of an animal, be it pet, or a rescue, can connect with vets, have a consultation chat with them. For general queries related to a pet's health,especially for people living in remote areas who cannot affort consultation, a rag system will also be put in place.

## Repository structure

| Folder      | What it is                                                             |
| ----------- | ---------------------------------------------------------------------- |
| `frontend/` | React + TypeScript web app (coming soon)                               |
| `backend/`  | Node + TypeScript API, Controller → Service → Repository (coming soon) |
| `rag/`      | Python service for the AI care assistant (coming soon)                 |
| `docs/`     | Requirements, data model, architecture, and decision records (ADRs)    |
